
1. **Метод расширения GetMax**:
   - Принимает необобщённую коллекцию и делегат для преобразования элементов в число.
   - Находит элемент с максимальным значением, используя приведение типа и сравнение через делегат.

2. **Класс FileSearcher**:
   - Использует `Directory.EnumerateFiles` для рекурсивного поиска файлов.
   - Генерирует событие `FileFound` для каждого найденного файла.
   - Поддерживает отмену поиска через свойство `Cancel` в аргументах события.

3. **События по .NET стандартам**:
   - `FileArgs` наследует `EventArgs` и содержит имя файла и флаг отмены.
   - Используется обобщённый `EventHandler<FileArgs>` для типобезопасности.

4. **Демонстрация в Main**:
   - Поиск самой длинной строки в коллекции через `GetMax`.
   - Поиск файлов с выводом в консоль и возможностью прерывания при нахождении .txt файла.
