**Реализация паттерна "Прототип"**

**Описание классов:**
1. **Person** (базовый класс):
   - Свойства: `Name` (строка), `Age` (целое число).
   - Описание: хранит базовую информацию о человеке.

2. **Employee** (наследник `Person`):
   - Свойства: `Position` (строка), `Salary` (десятичное число).
   - Описание: представляет сотрудника с должностью и зарплатой.

3. **Manager** (наследник `Employee`):
   - Свойства: `Department` (строка).
   - Описание: управленец, отвечающий за отдел.

4. **Student** (наследник `Person`):
   - Свойства: `Major` (строка), `GPA` (дробное число).
   - Описание: студент с направлением обучения и средним баллом.

**Вывод:**
- **`IMyCloneable<T>`**:
  - *Преимущества*: Типобезопасность, отсутствие приведения типов, гибкость.
  - *Недостатки*: Нестандартный интерфейс, требует явной реализации для каждого класса.

- **`ICloneable`**:
  - *Преимущества*: Стандартность, совместимость.
  - *Недостатки*: Необходимость приведения типов, риск ошибок времени выполнения.
